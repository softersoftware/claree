# Implementation

Previous: the [story refinement](06_refinement.md).

The makers implement the refined stories in the order of the roadmap, following their plan of implementation. Each implemented story can be tried by the domain experts before it reaches real people.

Next: when all the stories of a version are done, the version is [deployed](08_deployment.md).

## Risks

Building more than the story asks, or ahead of the roadmap: code nothing uses yet still costs to maintain and to change.

## Glossary

- **Starting a story**: taking it from to do to in progress.
- **Finishing a story**: taking it from in progress to done, once the domain expert could see it working.
